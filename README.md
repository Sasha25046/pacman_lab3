Лабораторна робота №3 — евристичний пошук та інтелектуальні агенти (Pac-Man-подібне середовище)

Етапи та кроки ускладнення задаються як `етап.крок`:
1.1 блукання, 1.2 жадібний, 1.3 пошук шляху | 2.1 засідка, 2.2 відсікач, 2.3 фланг |
3.1 спільні цілі, 3.2 перекриття виходів | 4.1 оптимальні ролі + штраф за скупчення, 4.2 кліщі, 4.3 адаптація до стилю гравця.

    python pacman_lab3.py              # гра, етап 4 (останній крок)
    python pacman_lab3.py 4.2          # гра на конкретному кроці; керування W/A/S/D або стрілки, Q — вихід
    python pacman_lab3.py bench 100    # серія експериментів (100 епізодів) -> results.csv
    python pacman_lab3.py demo 4.2 astar 3 runner --plain --frames 24-29
                                       # відтворювана демонстрація: етап.крок, astar|bfs, seed, greedy|runner

Приклади емерджентної поведінки зі звіту:

    python pacman_lab3.py demo 2.2 astar 37 runner --plain --frames 43-49
    python pacman_lab3.py demo 4.2 astar 3 runner --plain --frames 24-29
